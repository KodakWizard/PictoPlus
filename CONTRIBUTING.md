# Contributing

Thanks for helping with PictoPlus. Small fixes, clear bug reports and careful testing are all useful.

Before changing a working area, read [BUILDING.md](docs/BUILDING.md) and the relevant tests. Keep fixes focused. The USA loader, book identity and progress formats need particular care; don't change them just to tidy code.

For a bug report, include what you expected, what happened, the app/loader version, region and reproducible steps. For hardware reports, include the console or emulator and Luma version. A screenshot or a short, redacted log is helpful. Never post game dumps, setup profiles, saves or private resources publicly.

For a pull request, explain the user-visible change and the checks you ran. Separate automated results from physical hardware testing. Use a small original test fixture where possible. Model/artwork contributions need redistribution rights and attribution where required.

Original project contributions use MIT. Existing third-party and MPL-covered files keep their own licences and notices. Please don't add extracted game content, credentials, local paths, generated setup files or personal libraries to the repository.

AI-assisted contributions are welcome, but review the result, understand what it changes and test it. Mention material tool assistance when it helps a reviewer assess the change.
