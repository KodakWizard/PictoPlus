# Changelog

## 0.8.0 - first public release candidate

This is the first public candidate, bringing together the work from private development. Publication and release signing are still separate steps.

- Block designer with free and layer-by-layer editing, shape rotation, undo/redo and live saving.
- Independent Easy, Medium and Hard number layouts and fine-tuning controls.
- Book library, cover choices, custom artwork and shareable `.pictobook` exports.
- Experimental 3D conversion and attached reveal models.
- USA installed-game setup with no desktop ROM dump or manual save editing.
- Up to 210 puzzles per book, with paging and persistent custom-book identities.
- Buffered USA book reconstruction, preserving existing book formats and progress.
- Corrected completion-model camera presets and native artwork framing.
- Pinned desktop builds, dependency notices, clean-package verification and public build sources.
- Consistent mascot/icon assets and first-time setup documentation.

Known limits: Windows x64 desktop; USA public loader; experimental conversion; 71 persistent custom-book slots; unsigned executables. EUR and Linux are not part of this release. See the README and compatibility notes before installing.
