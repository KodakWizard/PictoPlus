Opening PictoPlus

Welcome to PictoPlus!

Just a few steps before you can start creating puzzles.

To get started, you'll need your installed USA copy of Picross 3D: Round 2. This is a one-time setup, and no game dump is required.

PictoPlus is already set up. You can review these steps or import a setup file again. Return to PictoPlus
1

Step 1 - Download the setup files

Extract the ZIP to the root of your 3DS SD card and enable Luma's plugin loader.

2

Step 2 - Launch the game on your 3DS

Open Picross 3D: Round 2 and wait for the setup to finish. Your existing books and saves will be preserved.

3

Step 3 - Finish setting up PictoPlus

Put your SD card back into your computer and import the setup file:

PictoPlus/PictoPlus-Setup.pictosetup

The setup file contains data from your game. Keep it private. You only need to import it once.

Currently supports the USA version. EUR support is separate.
