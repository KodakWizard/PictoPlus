PLAY YOUR CREATIONS

Your books, ready to play.

One book file for sharing, editing and playing. Each book can contain up to 210 puzzles.

How it works

  1. Set up your game once. Install the PictoPlus loader package for your game’s region.
  2. Export a book. PictoPlus creates a .pictobook file with its puzzles, cover and artwork.
  3. Add it to your books folder. Copy in your own books or books shared by other creators, then restart the game.

No Checkpoint restore or manual save editing is needed with the loader. Keep its progress files when adding books or updating the loader.

Nintendo 3DS with Luma

First-time setup

Copy the PictoPlus USA setup to the root of your SD card and enable Luma’s plugin loader. European setup is separate.

The loader prepares the files it needs from your installed USA game on first launch. No game dump or base folder is needed. Install the loader before adding books.

Adding more books

Copy each .pictobook into:

SD card / PictoPlus / Books

Restart Picross 3D: Round 2 to discover the added books. You do not need to reinstall the loader for each book.

Keep your existing PictoPlus books, registry and progress files when updating.

Use the corresponding emulator setup package. Copy your book files into its virtual SD card’s PictoPlus / Books folder, then restart the game. The book files are the same ones used on a 3DS.

Sharing a book

Send the exported .pictobook file. The recipient can copy it into their configured game’s books folder, or use Open file in PictoPlus to edit it.

Single puzzles are shared as books containing one puzzle. There is no separate pack file to choose.

Need a hand?

Everything you need to get your puzzles onto your 3DS.

Getting your puzzles onto your 3DS

1. Create your book

Start with My Book or create a new one, then add your puzzles.

2. Export your books

Open Book Library, select the books you want to play, and choose Export / install.

3. Copy them to your SD card

Copy your exported .pictobook files to:

SD:/PictoPlus/Books/

If you've exported several books as a ZIP, extract it first.

4. Start playing!

Put your SD card back into your 3DS and launch Picross 3D: Round 2.

First-time setup

Only need to do this once for each setup.

  1. Download USA SD Setup and extract it to the root of your 3DS SD card. Make sure Luma's plugin loader is enabled.
  2. Launch your installed USA copy of Picross 3D: Round 2 and let PictoPlus prepare the setup file.
  3. Return your SD card to your computer. Open PictoPlus and select Import setup file, then choose:

    PictoPlus/PictoPlus-Setup.pictosetup

Once imported, you're ready to start creating puzzles. No ROM dump required.

Sharing your books

Want someone else to try your puzzles? Just share the .pictobook file.

Other PictoPlus users can import it into the app to edit, or copy it to their Books folder to play.

Only share models and artwork you have permission to distribute.

Remember: Your PictoPlus-Setup.pictosetup file contains data from your game and should stay private.
